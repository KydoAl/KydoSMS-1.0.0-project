# KydoSMS

Initial FOSS-oriented Material 3 SMS project companion to KydoPhone.

Includes conversation grouping, unread counts, search, conversation view, SMS provider access, incoming SMS receiver, and GitHub Actions APK build.

This is a foundation, not yet a production SMS replacement: default-SMS-role handling, actual SMS sending, MMS, notifications, provider write operations, and complete contact integration should be finished before daily use.
